# Automatización de Reportes en Python

Este proyecto automatiza el filtrado de datos de ventas y genera reportes organizados automáticamente.

## Funciones
- Lee archivo CSV
- Filtra información
- Genera reporte automático

## Tecnologías usadas
- Python
- Pandas

## Cómo ejecutar

1. Instalar dependencias:
pip install pandas

2. Ejecutar programa:
python reporte.py
